/colophon_

A note on the design and craft of this site — fonts, tools, philosophy. Inspired by the tradition of book colophons.

how this site is made

Why this site exists

I built this site to be a portfolio, a documentation hub, and a contact card — in that order. Most of what I ship is open source, and most of my professional relationships come from people reading the READMEs first and then looking me up. This site is the answer to "who is the person behind SecSight / NetSage."

Design philosophy

Terminal-aesthetic + restrained type. The site should feel like a senior engineer's editor, not a marketing site. Dark by default. Information density is fine — whitespace is for emphasis, not decoration. Every animation must be earned: if a motion doesn't communicate hierarchy or state, it's noise.

Typography

System monospace stack — SF Mono → JetBrains Mono → IBM Plex Mono → Menlo → Consolas. No web font downloads. Headings and body use the same family to reinforce the "single editor" feel. Type scale uses clamp() so the layout never breaks across viewports.

Color

Three colors do all the work: ink (#e6e6e6) for primary text, indigo (#6366f1) for accent / brand, and emerald (#22c55e) for status / live indicators. Everything else is muted grays. No gradients except the radial wash on hero orbs. No drop shadows except an 8px subtle one on hovered buttons.

Motion

Five-act choreographed motion: opening title squash (only place spring easing is allowed), scroll-reveal with curtain wipe, cards stagger 70ms, mouse-follow 3D tilt, scroll parallax on figures. All animations use transform + opacity only (GPU-composited). prefers-reduced-motion is fully respected. WebGL particle strands in the hero run at 60fps on modern devices, fall back to CSS-only SVG on others.

Tools used

Built with: vanilla HTML + CSS + JS (no framework). WebGL 1.0 for the hero strands. Python + PIL for OG image generation. Cloudflare Pages for hosting. Cloudflare Email Obfuscation is OFF — your real email reaches me. No analytics, no tracking pixels. Just a static site that does what it says.

Inspirations

Rauno Freiberg, Tobias van Schneider, Bruno Simon, Linear, Vercel, Stripe Press, the React Bits Strands animation. Mostly: the senior engineer's portfolio genre — quiet competence over loud design.
