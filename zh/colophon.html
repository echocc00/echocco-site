/版权页_

关于本站的设计与工艺 — 字体、工具、哲学。借鉴书籍版权页的传统。

本站如何构建

为什么有这个站

我做这个站是把它当作品集、文档中心、和联系卡 —— 按这个顺序。我交付的大多数东西都是开源的,我大多数职业关系都来自先读 README 再查人。这个站是对"SecSight / NetSage 背后是谁"的回答。

设计哲学

终端美学 + 克制的字。站应该感觉像高级工程师的编辑器,不像营销站。默认暗色。信息密度没问题 —— 留白用于强调,不用于装饰。每个动画必须赚来:如果一个动作不传达层级或状态,就是噪音。

字体

系统等宽栈 — SF Mono → JetBrains Mono → IBM Plex Mono → Menlo → Consolas。不下载 web font。标题和正文用同一个字体族,强化"单一编辑器"的感觉。字号用 clamp(),任何视口下都不破。

颜色

三个颜色干所有活:ink (#e6e6e6) 主文字,indigo (#6366f1) 强调/品牌,emerald (#22c55e) 状态/实时指示。其他都是灰色。除 hero orb 的径向晕染,没有渐变。除按钮 hover 的 8px 微妙阴影,没有投影。

动效

五幕编排:开屏标题 squash(唯一允许 spring 的地方),滚动揭示窗帘擦除,卡片 stagger 70ms,鼠标跟随 3D 倾斜,滚动视差。所有动画只用 transform + opacity(GPU 合成层)。prefers-reduced-motion 完全尊重。hero WebGL 粒子 strands 现代设备 60fps,老设备降级到 CSS-only SVG。

使用的工具

构建于:原生 HTML + CSS + JS(无框架)。WebGL 1.0 用于 hero strands。Python + PIL 生成 OG 图。Cloudflare Pages 托管。Cloudflare 邮件混淆已关闭 — 你的真邮箱能到我这里。无分析,无追踪像素。就是一个说了做到的静态站。

灵感

Rauno Freiberg、Tobias van Schneider、Bruno Simon、Linear、Vercel、Stripe Press、React Bits Strands 动画。主要是:高级工程师作品集流派 — 安静的能力胜过响亮的设计。

许可证

本站内容(文案、布局、设计):CC BY 4.0。本站的源码:MIT。项目背后的代码:Apache-2.0(Hydro OJ fork 用 AGPL-3.0)。随便用。只是别假装是你写的。

版权页

等宽字体。MacBook Pro 上写。Cloudflare 边缘渲染。11 个区域的 4 个 nginx worker 提供服务。最后更新 2026-09-03。
