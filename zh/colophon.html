版权页

关于这个站怎么设计与制作的注记 —— 字体、工具、想法。灵感来自书籍版权页的传统。

本站如何构建

为什么有这个站

我做这个站是把它当作品集、文档中心、和联系卡 —— 按这个顺序。我交付的大多数东西都是开源的,我大多数职业关系都来自先读 README 再查人。这个站是对"SecSight / NetSage 背后是谁"的回答。

设计哲学

社论排版,不是仪表盘。站应该像一份排得好的刊物,不像控制台,也不像营销站。纸面底、栏线、和留白干卡片和投影干的活。信息密度没问题 —— 留白用于强调,不用于装饰。每个动画必须赚来:如果一个动作不传达层级或状态,就是噪音。

字体

Source Serif 4 排标题,Source Sans 3 排正文,JetBrains Mono 只排数值 —— 版本号、覆盖率、标识符。三个都自托管,浏览器不向第三方发字体请求。字号是一条从 12px 到 47.8px 的连续 1.2 阶梯,每一档都有东西在用。大字号是 clamp(),窄视口下字标会缩小,不会把布局撑破。

颜色

四个颜色干所有活:纸面 (#F2EEE6) 做底,ink (#1A1A1A) 做主文字,单一墨蓝 (#1D3B6E) 做强调和链接,绿 (#2F6B4F) 做实时状态。其他都是灰和两档栏线。没有渐变,没有投影 —— 一个都没有。

动效

一个签名动作,加一套滚动揭示。签名是报头:字标自己印出来,从网点半调筛里一层层收成实心墨。其余都是滚动触发的揭示 —— 窗帘擦除、上浮、图片遮罩 —— 子元素比父元素晚一拍。ledger 里有一个实时钟,覆盖率条在载入时填一次。所有动画只用 transform、opacity 和 clip-path,全部留在合成层上。prefers-reduced-motion 完全尊重。

使用的工具

构建于:原生 HTML + CSS + JS(无框架)。无 WebGL,无 canvas,无运行时依赖。Python + PIL 生成 OG 图。Cloudflare Pages 托管。Cloudflare 邮件混淆已关闭 — 你的真邮箱能到我这里。无分析,无追踪像素。就是一个说了做到的静态站。

灵感

Rauno Freiberg、Tobias van Schneider、Bruno Simon、Linear、Vercel、Stripe Press。主要是:高级工程师作品集流派 — 安静的能力胜过响亮的设计。
